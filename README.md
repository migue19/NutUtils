## Installation

NutUtils is available through [CocoaPods](https://cocoapods.org). To install
it, simply add the following line to your Podfile:

```ruby
pod 'NutUtils'
```

NutUtils is also available through the [Swift Package Manager](https://swift.org/package-manager/).
To install it, add it as a dependency in your `Package.swift` or via Xcode's
"Add Package Dependencies..." using the repository URL:

```
https://github.com/migue19/NutUtils.git
```

```swift
dependencies: [
    .package(url: "https://github.com/migue19/NutUtils.git", from: "1.1.8")
]
```
